# How to Add Insights to Your Dashboard

## 🎯 **Step-by-Step Guide**

### **Method 1: Through the Dashboard (Recommended)**

1. **Go to your dashboard**: https://us.i.posthog.com/project/238221/dashboard/615755

2. **Click "Add insight"** button (orange button with + icon)

3. **In the "Add insight" dialog**:
   - You should see a list of existing insights
   - Look for these specific insights:
     - "Series Views Over Time"
     - "Series Created" 
     - "Series by Name"
     - "Series Edits"
     - "Users Creating Series"
     - "Series Engagement"
   - Click on each one to add it to the dashboard

### **Method 2: Through Insights Section**

1. **Go to Insights section**: https://us.i.posthog.com/project/238221/insights

2. **Look for your insights** in the list:
   - Series Views Over Time (ID: 3801439)
   - Series Created (ID: 3801440)
   - Series by Name (ID: 3801441)
   - Series Edits (ID: 3801442)
   - Users Creating Series (ID: 3801443)
   - Series Engagement (ID: 3801444)

3. **For each insight**:
   - Click on it to open
   - Look for "Add to dashboard" button
   - Select "Cricket Series Analytics" dashboard

## 🔍 **Troubleshooting**

### **If you can't see the insights:**

1. **Check the Insights section**: https://us.i.posthog.com/project/238221/insights
2. **Look for "Series" in the search/filter**
3. **Make sure you're in the correct project** (238221)

### **If the dashboard is still empty:**

1. **Refresh the dashboard page**
2. **Check if insights were added** (they should appear as tiles)
3. **Try adding one insight at a time**

## 📊 **What You Should See**

Once you add the insights, your dashboard should show:
- 6 tiles with different charts
- Real-time data (once you start using the app)
- Auto-updating charts
- Series analytics data

## 🚀 **Next Steps**

After adding insights:
1. **Test the analytics** by creating series in your app
2. **Watch the dashboard update** in real-time
3. **Customize the layout** if needed

## 📞 **If Still Having Issues**

The insights definitely exist (we verified via API). If you still can't see them:
1. Check you're logged into the correct PostHog account
2. Verify you're in the correct project (238221)
3. Try refreshing the page
4. Check if there are any filters applied in the insights section
